# Hand Gesture Mouse Controller 🖐️🖱️

A computer vision project that uses a webcam and hand gestures to control a virtual mouse cursor.

## 🚀 Features

- 🖐️ Real-time hand tracking
- ☝️ Index finger cursor movement
- 🤏 Pinch gesture for clicking
- 📷 Webcam integration
- 📊 Real-time tracking information
- 🎨 Interactive web interface
- 📱 Responsive design

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- MediaPipe Hands
- Web Camera API
- Computer Vision
